# Задания на HTML и CSS

Практические работы из HTML/CSS-части курса. 49 статических страниц в 12 наборах заданий, папка на набор. Изображения каждого набора лежат в `img/`, шрифты — в `fonts/`.

| Папка     | Страниц | Темы                                                      |
| --------- | ------- | --------------------------------------------------------- |
| `task-01` | 7       | Базовые теги, разметка текста, формулы                    |
| `task-02` | 3       | Изображения, figure                                       |
| `task-03` | 3       | Внешние и веб-шрифты                                      |
| `task-04` | 8       | Фоны, центрирование, таблицы, шахматная доска и календарь |
| `task-05` | 8       | Блочная и табличная вёрстка, позиционирование, новости    |
| `task-06` | 6       | Рамки, меню, пагинация, визуальные ступени                |
| `task-07` | 3       | Адаптивные страницы и галереи фотографий                  |
| `task-08` | 3       | Формы, стилизация спрайтом, страница входа                |
| `task-09` | 2       | Видеогалерея, иконочные шрифты                            |
| `task-10` | 1       | SVG-анимация                                              |
| `task-11` | 3       | Кнопки, CSS-анимации, страница знаний                     |
| `task-12` | 2       | Адаптивная вёрстка на flexbox и grid                      |

## Просмотр

Страницы — чистые HTML и CSS без сборки, любой файл открывается в браузере:

```sh
xdg-open task-12/adaptive-layout-grid.html
```

## Образцы

`task-05/img/first-layout-page-example.png` — вид страницы, которую нужно повторить по заданию. На него не ссылается ни одна страница, и это осознанно.
