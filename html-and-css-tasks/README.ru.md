# Задания на HTML и CSS

Практические работы из HTML/CSS-части курса. 49 статических страниц в 12 наборах заданий, папка на набор. Ресурсы, нужные набору — изображения, шрифты, спрайты — лежат рядом с его страницами.

| Папка     | Страниц | Темы                                                      |
| --------- | ------- | --------------------------------------------------------- |
| `Task N1` | 7       | Базовые теги, разметка текста, формулы                    |
| `Task2`   | 3       | Изображения, figure                                       |
| `Task3`   | 3       | Внешние и веб-шрифты                                      |
| `Task4`   | 8       | Фоны, центрирование, таблицы, шахматная доска и календарь |
| `Task5`   | 8       | Блочная и табличная вёрстка, позиционирование, новости    |
| `Task6`   | 6       | Рамки, меню, пагинация, визуальные ступени                |
| `Task7`   | 3       | Адаптивные страницы и галереи фотографий                  |
| `Task8`   | 3       | Формы, стилизация спрайтом, страница входа                |
| `Task9`   | 2       | Видеогалерея, иконочные шрифты                            |
| `Task10`  | 1       | SVG-анимация                                              |
| `Task11`  | 3       | Кнопки, CSS-анимации, страница знаний                     |
| `Task12`  | 2       | Адаптивная вёрстка на flexbox и grid                      |

## Просмотр

xdg-open Task12/adaptive-layout-grid.html
