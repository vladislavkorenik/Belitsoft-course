# HTML and CSS tasks

Practical work from the HTML and CSS part of the course. 49 static pages across 12 task sets, one folder per set. Assets each set needs — images, fonts, sprite sheets — sit alongside its pages.

| Folder    | Pages | Topics                                            |
| --------- | ----- | ------------------------------------------------- |
| `Task N1` | 7     | Basic tags, text markup, formulas                 |
| `Task2`   | 3     | Images, figures                                   |
| `Task3`   | 3     | External and web fonts                            |
| `Task4`   | 8     | Backgrounds, centring, tables, chess and calendar |
| `Task5`   | 8     | Block vs table layout, positioning, news section  |
| `Task6`   | 6     | Borders, menus, pagination, visual steps          |
| `Task7`   | 3     | Adaptive pages and photo grids                    |
| `Task8`   | 3     | Forms, sprite-sheet styling, login page           |
| `Task9`   | 2     | Video gallery, icon fonts                         |
| `Task10`  | 1     | SVG animation                                     |
| `Task11`  | 3     | Buttons, CSS animations, knowledge list           |
| `Task12`  | 2     | Adaptive layout with flexbox and grid             |

## Viewing

The pages are plain HTML and CSS with no build step — open any file in a browser:

```sh
xdg-open Task12/adaptive-layout-grid.html
```
