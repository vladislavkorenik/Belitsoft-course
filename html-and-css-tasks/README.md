# HTML and CSS tasks

Practical work from the HTML and CSS part of the course. 49 static pages across 12 task sets, one folder per set. Each set keeps its images in `img/` and its fonts in `fonts/`.

| Folder    | Pages | Topics                                            |
| --------- | ----- | ------------------------------------------------- |
| `task-01` | 7     | Basic tags, text markup, formulas                 |
| `task-02` | 3     | Images, figures                                   |
| `task-03` | 3     | External and web fonts                            |
| `task-04` | 8     | Backgrounds, centring, tables, chess and calendar |
| `task-05` | 8     | Block vs table layout, positioning, news section  |
| `task-06` | 6     | Borders, menus, pagination, visual steps          |
| `task-07` | 3     | Adaptive pages and photo grids                    |
| `task-08` | 3     | Forms, sprite-sheet styling, login page           |
| `task-09` | 2     | Video gallery, icon fonts                         |
| `task-10` | 1     | SVG animation                                     |
| `task-11` | 3     | Buttons, CSS animations, knowledge list           |
| `task-12` | 2     | Adaptive layout with flexbox and grid             |

## Viewing

The pages are plain HTML and CSS with no build step — open any file in a browser:

```sh
xdg-open task-12/adaptive-layout-grid.html
```

`task-05/img/first-layout-page-example.png` shows the page the task asks you to reproduce. No page links to it — that is intentional.
