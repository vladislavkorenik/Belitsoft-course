# Belitsoft-course

Coursework from the Belitsoft front-end course. Each module lives in its own folder.

## Modules

| Module                                             | Folder               | Contents                                          |
| -------------------------------------------------- | -------------------- | ------------------------------------------------- |
| [JavaScript tasks](js-tasks/README.md)             | `js-tasks`           | 41 solutions across arrays, objects and functions |
| [HTML and CSS tasks](html-and-css-tasks/README.md) | `html-and-css-tasks` | 49 static pages across 12 task sets               |

## Layout

```
Belitsoft-course/
├── js-tasks/              JavaScript exercises, grouped by topic
└── html-and-css-tasks/    HTML/CSS practicals, one folder per task set
```

Each module has its own README with a per-topic breakdown.

## Provenance

This repository was renamed from `Course-js`; GitHub redirects the old URL indefinitely. Its original content now lives under `js-tasks/`.

`html-and-css-tasks/` was brought in with `git subtree` from a separate repository. That source repository has been deleted — this repository is the only maintained location. The original history is preserved in full — same commit SHAs, original author dates — and reachable from `main`:
