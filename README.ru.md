# Belitsoft-course

Учебные задания фронтенд-курса Belitsoft. Каждый модуль лежит в своей папке.

## Модули

| Модуль                                                   | Папка                | Содержимое                                  |
| -------------------------------------------------------- | -------------------- | ------------------------------------------- |
| [Задания на JavaScript](js-tasks/README.ru.md)           | `js-tasks`           | 41 решение по массивам, объектам и функциям |
| [Задания на HTML и CSS](html-and-css-tasks/README.ru.md) | `html-and-css-tasks` | 49 статических страниц в 12 наборах заданий |

## Структура

```
Belitsoft-course/
├── js-tasks/              задания на JavaScript, сгруппированные по темам
└── html-and-css-tasks/    практические работы по HTML/CSS, папка на набор заданий
```

У каждого модуля свой README с разбивкой по темам.

## Происхождение

Репозиторий переименован из `Course-js`; GitHub бессрочно перенаправляет старый адрес. Его исходное содержимое теперь лежит в `js-tasks/`.

Папка `html-and-css-tasks/` перенесена через `git subtree` из отдельного репозитория. Исходный репозиторий удалён — этот репозиторий единственное актуальное место. Оригинальная история сохранена полностью — те же SHA коммитов, исходные даты авторства — и достижима из `main`:

| Исходный репозиторий | Папка                | Импортированная вершина | Subtree-мерж |
| -------------------- | -------------------- | ----------------------- | ------------ |
| `HTML-and-CSS-Tasks` | `html-and-css-tasks` | `945ba65`               | `62de203`    |
