# Lian creative agency

Responsive multi-page website template for a creative agency.

## Structure

```
lian/
├── index.html       # Home page
├── portfolio.html   # Portfolio showcase
├── contact.html     # Contact page
├── CSS/             # Stylesheets
├── js/              # JavaScript files
└── img/             # Images and assets
```
